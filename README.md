# crypto-decepto
A little app/script that's made by using the tkinter and cryptography libraries in Python.
The purpose of the app is to provide a database where you can encrypt your texts/passwords, and access them later. A feature is gonna be a decoy password, where entering a certain passkey won't let you access the real ingredients in the safe but will direct you to a decoy, which can be your choice. 
It'll be all prettied up using tkinter, forming a usable user interface, rather than doing everything in the Python Terminal
